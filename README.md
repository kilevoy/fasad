# 🧱 Калькулятор фасадных кассет и НФС

> Расчёт навесной фасадной системы из кассет (КФ-1…КФ-4): геометрия фасадов и проёмов, площади, подсистема, утеплитель, мембрана, крепёж — и смета по прайсу из Excel. То, что раньше собиралось вручную, считается в браузере за минуты.

## Зачем

Расчёт навесного вентилируемого фасада (НВФ/НФС) — это десятки взаимосвязанных величин: площади фасадов за вычетом проёмов, количество кассет с учётом раскладки, подсистема, утеплитель, мембрана, саморезы и заклёпки, наружные и внутренние углы. Вручную это долго и подвержено ошибкам. Калькулятор считает геометрию и комплектацию по введённому проекту и формирует смету по актуальному прайсу.

## Что считает

- **Геометрия проекта** — валовая и чистая площадь фасадов (с вычетом проёмов, без ухода в минус), количество и площадь проёмов, наружные/внутренние углы.
- **Кассеты** — типы КФ-1…КФ-4, режимы раскладки (горизонтальная, вертикальная, квадрат), угловые кассеты.
- **Комплектация** — подсистема (варианты П- и Г-образных, рамная), утеплитель (1–2 слоя), мембрана, крепёж.
- **Смета** — расчёт по прайсу, загружаемому из Excel (`xlsx`) без переписывания логики (см. [PRICE_ADMIN.md](PRICE_ADMIN.md)).

## Технологии

React · TypeScript · Vite · xlsx (импорт прайса) · Vitest · GitHub Actions

Расчётное ядро отделено от интерфейса (`src/features/calculator/model/`) и покрыто тестами.

## Локальный запуск

```bash
npm install
npm run dev          # разработка
npm test             # тесты геометрии
npm run build        # production build
npm run price:import # импорт прайса из Excel
```

Тесты проверяют расчёт площадей, вычет проёмов, защиту от отрицательной площади, масштабирование по количеству фасадов и агрегацию по проекту. Запускаются в CI на каждый push.
